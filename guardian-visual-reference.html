Visual DNA

Dark operational, high-contrast Tenable.

Use a matte dark background, sharp rectangular surfaces, subtle white borders, Work Sans typography, and Tenable yellow only for active navigation, status, calls to action, and premium Guardian One cues.

Navigation

Sticky top menu

Hex logo, lowercase wordmark, compact tabs, active underline, badge on the right.

Hero

Oversized headline

Use one yellow highlight block inside the headline and a faint hex motif on the right.

Surface

Dense card grids

Cards are square-edged, quiet, and information-first. Avoid marketing-style floating cards.

Tokens

Color, typography, spacing.

These tokens are the portable contract for recreating the Guardian look in any builder or coding tool.

Core colors
--bg: #1a1a1a
--bg-card: #2a2a2a
--yellow: #d4f000
--grey-2: #a0a0a0
Typography

Work Sans

Use 800/900 for hero and section headings, 700/800 for labels and badges, 400/500 for body text. Do not use negative letter spacing outside display headlines.

Spacing

Large bands

Sections use 72px vertical padding on desktop, 48px on tablet/mobile. Cards use 28px to 32px internal padding.

States

Public, Guardian, Guardian One.

The reference implementation uses body-level state classes so a single page can expose different content based on user status.

view-public

Public / Non-Guardian

Show program overview, pathway, benefits, and CTA. Hide personal dashboard and gated status panels.

view-guardian

Guardian

Show user dashboard, certification status, and progress toward Guardian One gates.

view-g1

Guardian One

Show active Guardian One badge, cleared gates, summit status, and maintenance requirements.

How to ask tools to use this style.

Point design or coding tools to this page and ask them to follow the tokens and structure below. The live LATAM demo is the complete reference implementation.

Do not drift

Design constraints

Do not add gradients, rounded marketing cards, beige palettes, decorative blobs, or oversized explanatory UI text. Keep the experience operational and direct.
